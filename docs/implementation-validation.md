# Проверка реализации · 23 сентября 2026

Среда: Windows, Python 3.12.14, локальный Uvicorn на 127.0.0.1:8000. Режим `frozen_semantic` + `template`. Настоящие E5-эмбеддинги рассчитаны заранее; внешние LLM в этом прогоне не использовались.

## Автоматические проверки

Полный pytest: **141 passed** за 4.50 с после подключения типизированного ответа OpenAPI. `pip check` не нашёл конфликтов зависимостей. Есть предупреждение Starlette о будущей замене транспорта TestClient; ошибки и упавшие проверки отсутствуют.

Покрытие поведения: строгий парсинг, календарь, бюджет/формат/длительность/язык, первая причина, зарубежный каталог, None-длительность, формула/tie-break, 20 повторов, устаревшие векторы и факты, bounded LLM output, таймауты, ключи, конкуренция и перезапуск кеша. Дополнительно проверены 100 валидных комбинированных запросов и все возможные тройки профилей внутри города/категории на различимость фактов.

Отдельно отправлено **140 HTTP-запросов** к работающему серверу: каждый из семи сценариев повторён 20 раз, карточки и тексты совпали побайтно после JSON-разбора. Таблица показывает локальное время полного HTTP round-trip, а не обещание сетевой задержки внешнего сервиса.

## Проверка интерфейса

Проверено в браузере на работающем API: стартовая тройка, сравнение 4/5 октября, декораторы Астаны, отсутствие категории за рубежом, читаемая мобильная компоновка при ширине 390px. На двух датах ведущие меняются с Софи Хаттер/Джинбей/Кики на Софи Хаттер/Хаул/Буллма. API подтверждает busy для пропавших кандидатов; UI показывает эту причину.

JavaScript проходит `node --check`; внешних скриптов, шрифтов и CDN нет. Фронтенд выводит данные через `textContent`. API не показывает тела ошибок провайдеров/ключи. Compose YAML разобран локально.

## Границы проверки

- Живой Astra не проверен: нет фактического endpoint/model/контракта и ключей. Адаптер и резервирование проверены моками; текущий интерфейс честно показывает объяснение по фактам.
- Docker отсутствует в локальном окружении. Dockerfile, Compose и проверка сборки/healthcheck включены в CI; локальная контейнерная сборка не заявляется.
- Эти проверки подтверждают корректность правил и воспроизводимость. Они не доказывают качество подрядчиков, актуальность календаря вне датасета или оптимальность весов на реальных пользовательских выборах.
