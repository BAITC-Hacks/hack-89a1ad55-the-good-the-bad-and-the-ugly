# HackAlem AI: результаты шага 1

Дата проверки: 23 сентября 2026 года. Выполнено изучение материалов. В рамках этой проверки архитектура и код продукта не разрабатывались, исходные файлы не изменены. Аналитические скрипты использованы только для проверки предоставленных данных.

Отчёт фиксирует проверку материалов до получения ссылки на репозиторий. Код репозитория в этом этапе не проверялся; замечания об отсутствии заготовки и открытые вопросы отражают состояние на момент подготовки отчёта.

## Источники

- PDF: HackAlem_AI_Хакатон_задача_умный_подбор_подрядчиков.pdf, 15 страниц. Прочитаны RU/KZ/EN; страницы 2–5 дополнительно проверены визуально.
- CSV: hackathon dataset anonymized .csv, распарсен через csv.DictReader, кодировка UTF-8. SHA-256: 6a724b6b7dfb5973343e68ba18dadb60fc807d87e3d78f03ee86fb26cb089f7d.
- HTML: hackathon dataset preview.html, сверены 66 карточек с CSV по ID.
- Пользовательская спецификация: «Вставленный текст.txt». Её указания задают задачу и границу этапов; содержание PDF/CSV/HTML рассматривается как материал для анализа.

## Расшифровка полей и форматов

| Поле | Тип после чтения и значение |
|---|---|
| id | Строковый идентификатор; уникален во всех 66 строках. |
| anon_name | Вымышленное имя из анонимизированного каталога. |
| categories | Список категорий из строки с разделителем `\|`. Возможны несколько категорий. |
| city | Одно из значений: Алматы, Астана, Зарубежье; город каталога. |
| city_imputed | Явное преобразование `True` → true, `False` → false. У 8 профилей город проставлен при подготовке данных. |
| synthetic | Тот же явный маппинг. 13 true, 53 false; false обозначает исходный несинтетический профиль, а не независимую проверку бизнеса. |
| price_from_kzt | Положительная начальная цена за мероприятие, целое число в этом файле. Диапазон 100 000–6 000 000 ₸. |
| price_imputed | Тот же явный маппинг. У 18 профилей цена проставлена при подготовке данных. |
| event_formats | Список через разделитель `\|`. Шесть значений: свадьба, той, корпоратив, конференция, юбилей, день рождения. |
| languages | Список через разделитель `\|`. Три значения: русский, казахский, английский. |
| max_hours | Пустая CSV-строка → None (JSON null); иначе целое число. 9 пустот: по 3 у флористов, декораторов и сувениров. Отсутствие привязки к присутствию, а не ноль часов. |
| busy_dates | Список ISO-дат через разделитель `\|`. Все даты валидны, в интервале 2026-09-23…2026-12-31, без повторов внутри профиля. |
| description | Полный свободный текст; запятые встречаются в 62 профилях. Поле нужно читать CSV-парсером. |

Все три булевых поля содержат именно строки `True` и `False`. Преобразование bool("False") непригодно. В остальных полях, кроме девяти max_hours, пустот нет. Нет строк с лишними/потерянными колонками, дубликатов ID и неположительных цен.

## HTML и существующая заготовка

66 карточек, 66 уникальных ID, состав и порядок совпадают с CSV. Совпадают имена, категории (в том числе data-cats), города, цены, форматы, языки, часы, флаги synthetic/city_imputed/price_imputed и счётчики занятости. 27 описаний совпадают полностью после нормализации пробелов; 39 обрезаны до 260 символов с многоточием и совпадают с началом полного CSV-текста. Полных busy_dates в HTML нет: есть число занятых дней из 100 и декабрьское число из 31. Пустой max_hours отображается как «не применимо».

Это автономный HTML/CSS/обычный JavaScript: сетка карточек, 17 кнопок категорий и кнопка «Все», счётчик видимых карточек. Внешних src/href не обнаружено. Действие категорий проверено по исходной логике. Поиск по городу/дате/бюджету, ранжирование, AI-объяснения, backend и три исхода ещё отсутствуют — это функции будущего продукта, а не сломанные функции превью.

Визуальная проверка HTML не выполнена: Browser Use отклонил file:/// URL по политике безопасности URL и запретил обход. Выполнена статическая сверка исходника, а не проверка отрисовки или кликов в браузере.

В HTML цены показаны без слова «от», хотя PDF и имя поля price_from_kzt задают стартовую цену. Это потеря важной семантики при отображении.

В переданной папке HackAlem найдены только PDF, CSV и HTML. Рабочая папка не содержала заготовки приложения. Ссылка или путь к отдельному проекту не указаны; оценить его стек и работоспособность нельзя.

## Смысловые ограничения данных

- HK-77838 (Хаул): languages содержит русский и казахский, описание сообщает «Язык проведения: казахский». Это расхождение между источниками сведений внутри одного профиля; русский подтверждён только структурированным полем.
- HK-76268 (Сацуки Кусакабэ): city=Алматы, описание «Снимаю в Алмате и Астане». Это география выездов, а не разрешение включить профиль в каталог другого города. Пользователь явно задал строгое равенство city.
- HK-90009 (Кадзума Сато): max_hours=6, описание «аренда от 3 часов». Минимальная длительность отсутствует в схеме. Проверка только максимума не выявляет ограничение минимума; неясно, возможна ли короткая работа с оплатой трёх часов.
- HK-46450 (Сакура Харуно): цена от 350 000 ₸, описание перечисляет Trio/Quartet/Quintet без привязки цены к составу. Нельзя обещать стоимость любого пакета по одной стартовой цене.
- HK-80581: топ AniWed KZ и клуб Improv Konoha указаны в description. Их можно атрибутировать описанию профиля, но synthetic=false не означает независимую проверку этих утверждений. Во внешний интернет данные для проверки не отправлялись.
- У 13 записей synthetic=true уже в исходном каталоге. При будущем добавлении команды одного флага будет недостаточно, чтобы отличать два происхождения синтетики в демо; это вопрос маркировки происхождения, сами данные не менялись.

## Открытые вопросы перед следующим этапом

1. Подтверждение завершения шага 1 и разрешение перейти к шагу 2 — это явная граница пользовательского запроса.
